## TIde 1.0

The first major version.

- **Docs view:** the catalog is now a Docs view with a full page for every command, function and instruction. Click an entry to read it, or press Enter or **+** to insert it.
- **eZ80 assembly:** `.asm`, `.s` and `.src` files get highlighting, completions, hover docs and their own docs: the full instruction set, fasmg directives and common TI-OS routines.
- **TI-BASIC:** every command in the tokenizer now has a description, grouped by topic.
- **New layout:** an activity bar, side bar and status bar like VS Code, in TIde's colors. `Ctrl+B` hides the side bar.
- **Updates:** TIde checks for new versions when it starts and shows these notes. Click the version in the status bar to check now.
- **Status bar:** names the open project and takes the color of the active toolchain: TI-BASIC, C, py2ez80 or eZ80 assembly.
