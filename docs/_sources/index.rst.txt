Develop TIde extensions
=======================

This documentation is exclusively about creating add-ons for TIde. Extensions can add language
support, snippets, completions, hover help, editor commands, and calculator or project tools.

Start with :doc:`extensions` to create an extension, understand its manifest and JavaScript API,
test it in TIde, and package it for sharing.

The guide includes static contributions for snippets, completions, hovers, and languages; examples
for dynamic JavaScript providers and commands; notes on extension lifecycle and paths; and a
publishing checklist.
